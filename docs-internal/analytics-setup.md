# מדידת שימוש — GoatCounter (מדריך הפעלה, 5 דקות)

**ההחלטה:** GoatCounter. חינם לאתרים לא-מסחריים, קוד פתוח, בלי עוגיות ובלי מזהה אישי (סופר "מבקר ייחודי" ליום לפי hash של IP+דפדפן שנמחק כל יום), אירועים מותאמים, לוח בקרה פשוט בעברית-ידידותית (RTL לא נדרש). לא צריך באנר עוגיות.
הקוד באפליקציה כבר מוכן ורדום: `const ANALYTICS = { code: "" }` ב-`docs/index.html`. עד שממלאים קוד — לא נטען שום דבר.

## מה תעשה (פעם אחת)
1. גלוש ל-https://www.goatcounter.com/signup
2. **Code** (תת-הדומיין): `yampalata` → הלוח יהיה ב-`https://yampalata.goatcounter.com`
3. **Domain**: `yuvartz.github.io`
4. **Timezone**: Asia/Jerusalem · אפשר לסמן "Public dashboard" אם בא לך שהסטטיסטיקה תהיה גלויה.
5. אשר את המייל. זהו. **תגיד לי את הקוד** (`yampalata` או מה שבחרת) ואני מציב אותו ב-`ANALYTICS.code` ודוחף.

## מה תראה בלוח, ואיך זה עונה על השאלות שלך
| השאלה | איפה בלוח |
|---|---|
| **כמה יוזרים?** | Dashboard → "Visits" (מבקרים ייחודיים ליום/שבוע/חודש). זה המספר. |
| **כמה התקינו?** | Events → `event:app-installed` (אנדרואיד/דסקטופ — האירוע האמיתי) + `event:launch` עם `installed` בכותרת (כל פתיחה מהאייקון, כולל iPhone — שם אין אירוע התקנה, אז זה המדד) + `event:installed-daily-active` = כמה משתמשים מותקנים פעילים ביום |
| **מה הם עושים?** | Events: `beach · <חוף>`, `day-nav`, `camera-open` / `camera-photo · gps/no-gps`, `share`, `notifications · granted/denied`, `sound · on/off`, `feedback · <דרגה>`, `intro-shown`, `install-tap` |
| **כמה משתמשים חוזרים?** | `event:launch` — הכותרת מכילה `first` / `returning-early` (2–5 ביקורים) / `regular` (6+). אין מזהה משתמש; הדלי נשמר מקומית במכשיר. |
| מאיפה מגיעים | Referrers (וואטסאפ מופיע כ-direct, פייסבוק/אינסטגרם מזוהים) |
| מכשירים/מסכים | Browsers · Systems · Sizes |

## מה זה לא נותן (ובכוונה)
- אין מעקב אחרי אדם ספציפי, אין מיקום מדויק (רק מדינה), אין רצף פעולות של משתמש בודד. זה המחיר של "בלי הסכמה ובלי עוגיות" — ומתאים לאפליקציה כזאת.
- אם בעתיד תרצה משפכים אמיתיים (retention curves), נעבור ל-PostHog/Umami עם מזהה אנונימי — צריך אז הודעת פרטיות.
