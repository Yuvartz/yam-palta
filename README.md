# 🌊 ים פלטה (Yam Plata)

**מתי הים באמת רגוע?** אפליקציית ווב (PWA) בעברית שעונה על השאלה האחת שחשובה לשחיינים,
סאפיסטים ואנשי ים: האם עכשיו (או מחר) יש "ים פלטה" — ים שטוח ורגוע.

**כתובת:** https://yamplata.com/

## מה יש בפנים

- **מדד הפלטה (0–10)** — ציון משוקלל מארבעה גורמים: גובה גל (35%), גלים קצרים מהרוח (25%),
  רוח נוכחית (25%) והיסטוריית רוח 10 שעות (15%), עם תקרה קשיחה לפי גובה גל.
  ההגדרה היחידה: [docs/palata.js](docs/palata.js), משותפת לאפליקציה ולשולח ההתראות.
- **אנסמבל מודלים** — התחזית היא חציון של מודלים ימיים (MFWAM, ECMWF-WAM) ואטמוספריים
  (ECMWF-IFS, ICON); הפער בין המודלים הופך למשפט אמון ("המודלים מסכימים").
- **עוגן מציאות** — מדידה אמיתית ממצוף חדרה (ISRAMAR) מוצגת מול התחזית.
- **מדוזות** — דיווחי גולשים מ-meduzot.co.il עם התראת קרבה (25 ק"מ / 48 שעות).
- **התראות** — בדפדפן כשהאפליקציה פתוחה, ו-Web Push למסך נעול דרך Cloudflare Worker קטן (`workers/push`: אחסון מנויים פרטי, בדיקה כל 15 דק׳, מקסימום 2 התראות ביום + תצוגה מקדימה ל-19:00, שעות שקט, כיבוי מהאפליקציה). הפעלה: SETUP-PUSH.md.
- **20 חופים** — ישראל, סיני ויוון, פלוס "📍 קרוב אליי", מיקום מותאם והדבקת קישור Google Maps.
- **השבוע** — כרטיס אחד: לכל יום 14 עמודות זעירות (06 מימין → 19 משמאל), גובה וצבע רציף לפי המדד (אינטרפולציה ב-OKLab בין צבעי הדרגות), ◆ שיא היום, קו "עכשיו", קו סף 8.0, נקודות לילה; אחוז שעות הפלטה והשיא; לחיצה פותחת פירוט לכל שעה.
- **📷 צלם את הים** — פותח את המצלמה, מאתר את החוף הקרוב (GPS, עד 40 ק״מ) ומטביע על התמונה את מדד הפלטה, הדרגה, טמפ׳ המים, השעה והחוף; שיתוף ישיר או שמירה. בלי מיקום — המדד של החוף שנבחר, ונאמר כך.
- **מגמת טמפ׳ מים** — 7 ימים אחורה ו-3 קדימה, עם השינוי מלפני שבוע.
- **שיתוף** — Web Share / העתקה עם קישור עמוק (`?b=<חוף>`) שפותח את החוף ישירות.
- **צלילים והפטיקה (אופציונלי, כבוי כברירת מחדל)** — ים אמביינטי מסונתז ב-WebAudio שנושם בקצב הגלים האמיתי, תקתוק עדין במעברים, צלצול קצר כשיש פלטה. אין קובצי אודיו.
- מסך שיא חום מים היסטורי, זריחת/שקיעת ירח, UV, תצוגת גלים חיה מונפשת לפי מצב הים.

## ארכיטקטורה

אין build, אין framework — קובץ HTML אחד בזמן ריצה. (תלויות רק בצד הכלים: `web-push` לשליחת התראות, Pillow/NumPy לסקריפטי האייקונים.)

```
docs/                  ← מוגש ע"י GitHub Pages
  index.html           ← כל האפליקציה (markup + CSS + JS)
  palata.js            ← מתמטיקת המדד + נוסחי ההתראות (משותף לדף ול-send-push)
  sw.js                ← Service Worker: offline, קאש, Web Push
  manifest.json        ← PWA (RTL, עברית, מסך מלא)
  splash/, icon-*.png  ← נוצרים ע"י scripts/build-app-icons.py
  img/waves/           ← ספרייטים של גלים (נוצרים ע"י scripts/build-wave-sprites.py)
  data/                ← נכתב ע"י GitHub Actions (מצוף + מדוזות)
workers/push/          ← Cloudflare Worker: /subscribe /unsubscribe /test + cron כל 15 דק׳ (policy.js = מה נשלח ומתי)
scripts/
  fetch-buoy.mjs       ← מצוף חדרה (ISRAMAR) → docs/data/hadera-waves.json (כל שעה)
  fetch-jellyfish.mjs  ← דיווחי מדוזות → docs/data/jellyfish.json (כל שעה)
  build-app-icons.py   ← אייקונים, splash, badge (Pillow)
  build-wave-sprites.py← חיתוך ספרייטי הגלים מהארטוורק
  build-og-image.py    ← תמונת השיתוף og-image.png (1200×630)
```

## פיתוח מקומי

```bash
cd docs && python -m http.server 8000
```

ולפתוח http://localhost:8000. אין תהליך build — עורכים את index.html ומרעננים.
אחרי שינוי בקבצי ה-shell יש להקפיץ את `VERSION` ב-sw.js כדי שמשתמשים קיימים יקבלו אותו.

## המדד — הנחות ומגבלות

- המדד מתאר **שטיחות הים** (גלים ורוח), לא "בטוח לשחות": מדוזות, טמפ׳ מים, זרמים ודגלי מציל הם שיקולים נפרדים.
- ללא גובה גל **וגם** רוח נוכחית אין ציון (מוצג "—") — נתון חסר לא נספר כניטרלי.
- תקרת גובה גל: מעל 0.35 מ׳ המדד לא עובר 7.9; מעל 0.7 → 5.9; מעל 1.0 → 3.9; מעל 1.5 → 2.9; מעל 2.2 → 1.9.
- אחוזי "% זמן פלטה" = חלק משעות האור (זריחה→שקיעה אמיתיות) שבהן התחזית עומדת בסף 8.0 — לא הסתברות.
- כיווני רוח/גל ממוצעים כוקטורים (ממוצע של 350° ו-10° הוא צפון, לא דרום); כיוון לא יציב מוצג כ"—".
- במצב לא מקוון מוצגת התחזית האחרונה שנשמרה, עם אזהרה וזמן השמירה; לא נשלחות התראות מנתונים שמורים.

## פרטיות

אין חשבון ואין עוגיות. מדידת שימוש אנונימית (GoatCounter: ספירת ביקורים ואירועים כמו "חוף נבחר" / "שיתוף", בלי מזהה אישי ובלי מיקום מדויק) נטענת רק כש-`ANALYTICS.code` מוגדר. הדף פונה ל-Open-Meteo (קואורדינטות החוף), Google Fonts, Nominatim/OpenStreetMap
(רק כשמדביקים קישור מפות) ו-Google Forms (רק כששולחים דיווח או נרשמים להתראות). הכל נשמר מקומית בדפדפן.

## התקנה כאפליקציה

- **אייפון:** ספארי → שיתוף → "הוסף למסך הבית". התראות (iOS 16.4+) עובדות רק אחרי ההתקנה.
- **אנדרואיד/דסקטופ:** כפתור ההתקנה בדפדפן או 📲 בסרגל העליון.
