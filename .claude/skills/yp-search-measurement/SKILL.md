# Measurement and follow-through

Use only authorized existing data and local tools. Do not access credentials, connect accounts, verify ownership, enable analytics, deploy tracking, request indexing, submit sitemaps or send data to external audit services under a routine review task.

Separate technical readiness, actual index status, search impressions/clicks and successful product use. A valid title or fast page does not prove an indexing or traffic improvement. A search operator returning no result is not definitive evidence of exclusion. Use supplied Search Console reports or authorized read-only access if available; otherwise state the evidence gap.

For this GitHub Pages app, an exact URL-prefix Search Console property for https://yuvartz.github.io/yam-palta/ is a possible owner setup path. Do not assume ownership of github.io DNS or invent a verification token. Prepare clear owner instructions only, and verify current Google setup guidance before providing procedural steps.

Define a baseline period and comparison period. Interpret changes alongside seasonality, weather interest, releases and data coverage. Avoid attributing every traffic change to the latest metadata edit. Low traffic or missing field metrics is an absence of evidence, not a zero score.

Review load, responsiveness and layout stability with existing tooling. If reporting Core Web Vitals, distinguish LCP, INP and CLS, lab diagnostics and real-user field evidence; a local Lighthouse score alone does not prove field compliance. Use yp-web-performance if installed for measured code improvements rather than duplicating speculative optimization work.

Propose a minimal measurement plan tied to real questions, such as finding a forecast or returning to a saved beach. Do not implement analytics collection automatically. Exclude precise user locations and identifiers by default; any future instrumentation needs an explicit provider, data, retention and consent decision appropriate to the project.

Report local fixes, expected effects, owner-only actions and a reasonable observation plan without guaranteeing results or requesting unnecessary access.
