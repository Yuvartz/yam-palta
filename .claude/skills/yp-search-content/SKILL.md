# Helpful content and search intent

Work within the existing application's scope. Do not mass-generate pages, scrape competitors, purchase links, send outreach, publish content or install keyword/AI services.

Start from actual user questions and supported features. Candidate intents such as sea conditions in Tel Aviv, wave height, calm periods or sea temperature are hypotheses, not verified search-volume findings. Use supplied Search Console data when available; never fabricate traffic, demand or rankings.

Write clear Hebrew titles, headings and concise explanatory text with natural vocabulary. Explain what the flatness index means, what data contributes to it, its valid time and limitations using actual palata.js logic and approved documentation. Do not turn a score into a probability or guarantee safety.

Keep the main forecast task prominent. Use visible progressive disclosure for secondary explanations where appropriate; don't add hidden SEO paragraphs, repeated keywords or an unrelated blog. Add FAQs only for real recurring questions with grounded answers, not to meet a checklist.

If location pages would help, propose a small set with genuinely distinct useful content and working URLs before building. Avoid thin pages that merely substitute a beach name. Do not expose user-defined private locations or generate unverifiable local claims.

For AI-answer discoverability, prioritize accessible text, consistent entities/units, meaningful source attribution and trustworthy freshness. Google says its AI search features require no special AI file or special schema. Do not claim llms.txt, an invented GEO score or a particular wording guarantees citations in Google or other assistants. Check other providers' current primary documentation before making provider-specific claims; crawling for search and crawling for training are separate policy choices.

Review factual accuracy and real user usefulness before treating the content as an SEO improvement. Record proposed opportunities separately from approved implementation.
